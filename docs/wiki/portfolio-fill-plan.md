# Plano de preenchimento do portfolio

## Objetivo

Transformar a estrutura em branco do site em uma v1 vendável para um editor de vídeo freelancer focado em games.

O portfolio deve ser simples, direto e visual, com foco em:

- mostrar qualidade de edição;
- mostrar domínio de conteúdo de games;
- facilitar contato;
- evitar excesso de texto;
- não inventar clientes, métricas ou resultados.

## Ordem de preenchimento

### 1. Posicionamento

Coletar:

- nome profissional;
- idioma do site;
- nicho principal;
- tipos de conteúdo editados;
- plataformas alvo;
- canal de contato principal.

### 2. Materiais visuais

Coletar:

- showreel de 30–60s;
- 3 vídeos editados;
- se possível, trechos de antes/depois;
- thumbnails ou imagens de apoio;
- links de YouTube, TikTok, Instagram, Drive ou arquivos locais.

### 3. Home

Preencher:

- headline;
- subtítulo;
- showreel;
- CTA principal;
- 3 provas rápidas de serviço.

### 4. Cases

Criar 3 cases:

- Case 01: short vertical de gameplay;
- Case 02: highlight de stream;
- Case 03: vídeo longo para YouTube gaming.

Cada case deve conter:

- contexto;
- material bruto;
- problema;
- edição feita;
- antes;
- depois;
- resultado, se houver;
- link ou embed.

### 5. Serviços

Preencher três blocos:

- Shorts / Reels / TikToks;
- Vídeos longos para YouTube;
- Pacote streamer.

### 6. Processo

Explicar o processo em 5 passos:

1. Cliente envia o material bruto.
2. Editor seleciona os melhores momentos.
3. Editor faz a primeira versão.
4. Cliente revisa.
5. Editor entrega pronto para postar.

### 7. Contato

Preencher:

- WhatsApp;
- Discord;
- Email;
- Instagram/TikTok/YouTube, se houver.

## Regras

- Não inventar clientes.
- Não inventar views.
- Não inventar métricas.
- Não inventar cases.
- Usar placeholders quando faltar material real.
- Priorizar clareza e impacto.
- Manter o site simples.
- Publicar uma v1 antes de tentar deixar perfeito.

## Resultado esperado

Ao final, o site deve ter:

- uma Home clara;
- um showreel ou placeholder visível;
- 3 cases reais ou parcialmente preenchidos;
- serviços claros;
- processo simples;
- contato fácil;
- conteúdo publicado no GitHub Pages.
