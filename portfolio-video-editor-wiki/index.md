# Portfolio Video Editor — Wiki

Esta wiki serve para organizar o projeto do portfolio MVP antes e durante a construção do site.

## O que fica aqui

- **Posicionamento do editor** — quem é, para quem edita, o que entrega
- **Estrutura do portfolio** — mapa de páginas e seções do site
- **Cases** — projetos de referência com antes/depois e contexto
- **Materiais brutos** — inventário de assets, links e arquivos pendentes
- **Decisões** — escolhas de estrutura, stack, conteúdo e publicação
- **Pendências** — o que falta preencher, validar ou produzir
- **Logs de sessão** — registro do que foi feito a cada sessão no Cursor

## Como usar

1. Comece pelo [brief](brief.md) para levantar informações do editor.
2. Refine o [posicionamento](positioning.md) com base no brief.
3. Consulte o [mapa de conteúdo](content-map.md) ao montar o site.
4. Use o [template de case](cases/case-template.md) para documentar projetos.
5. Ao encerrar cada sessão, atualize [session-log](sessions/session-log.md) e, se necessário, [decisions](decisions/decisions.md) e [content-map](content-map.md).
